# dnd generator

О чем проект:
Проект представляет собой веб-приложение для автоматизированной генерации и систематизации игровых персонажей по правилам настольной ролевой игры D&D 5e. Сервис позволяет пользователям легко создавать уникальных героев с проработанной предысторией и характеристиками, а также управлять их хранением в личном кабинете.

Как это работает:
При отправке формы приложение формирует структурированный промпт и передает его через requests к внешнему REST API нейросети, которая возвращает готовое описание персонажа. Полученные данные очищаются от технических меток регулярными выражениями и сохраняются в базу данных SQLite через ORM-интерфейс SQLAlchemy. Вся последующая работа с персонажами, включая их отображение в профиле и экспорт в текстовые файлы, реализуется за счет серверной логики Flask и динамических HTML-шаблонов.
